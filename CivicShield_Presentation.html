Innovation — The India Proxy Strategy

Solving the closed-API problem

India's official portals (NCS, IMD, CWC, SACHET) have no public APIs. Rather than abandon India-specific data, we engineered authoritative open substitutes for each — attributed transparently.

Indian AuthorityAPI?Our Open SubstituteEngineering Approach
NCS — SeismologyClosedUSGS FDSN, India bbox68–98°E / 6–38°N bounded query, mag ≥3.0, BIS seismic-zone severity mapping
CWC — Water CommissionClosedOpen-Meteo GloFAS18 river gauge stations; GloFAS is the same model CWC itself uses
IMD — MeteorologyClosedOpen-Meteo Forecast18 cities; season-aware heatwave, cold wave, rainfall, cyclone-wind thresholds
SACHET — NDMA AlertsClient-renderedAuto-alert pipelineCron auto-dispatches High/Critical India events across 5 channels
Global multi-hazardOpenGDACS + NASA EONETRSS + India bbox query; category normalization into unified event model
Fire detectionOpenNASA FIRMS VIIRSIndia bbox CSV; Fire Radiative Power → severity classification
Deduplication engineering: The global USGS poller explicitly excludes the India bounding box so that Indian earthquakes are owned exclusively by the NCS-proxy poller — preventing the same quake appearing twice with different severities. All events upsert on a deterministic dedup_hash.

CivicShield AI vs. NDEM (ISRO / NRSC)

NDEM is India's national geospatial disaster repository, built by NRSC/ISRO under the Ministry of Home Affairs. It is authoritative and satellite-grade — but architecturally solves a different problem than ours.

Our honest position: We do not claim to replace NDEM — it has satellite assets and institutional authority we cannot match. CivicShield fills the gap NDEM structurally leaves open: the citizen-facing, real-time, bi-directional layer. The two are complementary; NDEM is the authoritative backbone, CivicShield is the public nervous system.

Feature Set — Part 2

The AI & Intelligence Layer

We label every model honestly — validated statistical models, rule-based classifiers, and true ML are each marked as what they are.

📈Risk Forecasting Prophet

Facebook Prophet time-series with yearly/weekly seasonality and 80% confidence intervals. Falls back to linear extrapolation if unavailable. Confidence derived from coefficient of variation.

📷AI Photo Classifier Live ML

Citizen incident photos classified via HuggingFace Inference API (ResNet-50). Returns damage type + suggested severity + confidence into the coordinator queue. Fails gracefully — never blocks submission.

⚖️Severity Calibration Rules

ML service re-scores every ingested event. Overrides the source severity only when confidence ≥ 0.80 — otherwise the original stands. Silent degradation if ML is unreachable.

🌊Flood Risk — India

Prophet forecast of river discharge against CWC danger levels using real GloFAS data across 18 gauge stations → Critical/High/Medium/Low.

🌏Earthquake Risk — India

NDMA seismic-zone base score combined with Gutenberg–Richter exponential weighting of real USGS history within 300 km / 30 days → 0–100 score.

🚚Resource Optimization

Google OR-Tools Vehicle Routing with Haversine distance matrix and guided local search. Greedy allocation consumes supply and reports unmet demand + fulfillment rate.

Academic honesty: Misinformation screening and base severity classification are rule-based (regex patterns + source-credibility allow-lists), not trained models — and we label them as such in code, docs, and UI. The photo classifier is genuine ML; ResNet-50 is a general-purpose classifier, so its output is presented to coordinators as an "AI suggestion," never as ground truth.

Technical Implementation — Security

Defence in Depth

Authorization is enforced independently at four layers. A bug in any one layer does not expose data.

①Identity

Supabase Auth issues JWTs. A user_profiles row is auto-created by a database trigger on signup with a default citizen role — privilege cannot be self-assigned at registration.

②API Layer

stateScope middleware verifies the JWT, then loads role and state server-side. Route handlers enforce role checks; coordinators are auto-scoped; destructive routes require coordinator/admin.

③Database

PostgreSQL Row-Level Security on every table with least-privilege grants. Anonymous role has SELECT only. Even a fully compromised API cannot read cross-state data.

④Real-Time

Socket.io handshake verifies the JWT before room assignment. Rooms are server-assigned from verified claims — a client cannot subscribe to another state's channel.

🛡️Hardening

  • Helmet security headers
  • CORS allow-list (no wildcards)
  • Global + per-route rate limiting
  • XSS escaping in all alert content

✅Validation

  • Zod schemas on every write route
  • Strict object parsing
  • Enum-constrained status fields
  • Incident submit capped 5 / 10 min

📋Accountability

  • Audit log on every state change
  • Reviewer ID + timestamp on reports
  • Rejection requires written reason
  • Admin-only audit log access

Social Impact

Who this actually helps

⏱️
Minutes matter in disaster response
Golden-hour survival rates fall sharply after the first 60 minutes. Sub-second alert propagation across five channels — including SMS, which works on feature phones without internet — directly compresses time-to-awareness.
📶
Designed for low-connectivity India
Service worker caches map tiles for offline viewing. SMS and WhatsApp reach users with no smartphone or data. The PWA installs in under 2 MB.
🗣️
Language is an access barrier
Alerts translate into Hindi, Tamil, Telugu, Bengali, Gujarati, Marathi, and Punjabi — an English-only alert excludes the majority of at-risk populations.
👁️
Citizens as sensors
Satellite and station networks cannot see a collapsed footbridge or a blocked evacuation road. Verified citizen reports fill the ground-truth gap that no remote-sensing system can cover.
🏛️
State-level operational autonomy
India's disaster response is constitutionally state-led. Jurisdiction scoping is built into the data model — coordinators see and act on their state only, with a national view reserved for administrators.
🔍
Misinformation is a disaster multiplier
Panic-driven false reports cost lives and misdirect resources. Automated credibility screening flags suspicious content before it propagates through official channels.
Design principle throughout: every feature degrades gracefully. If the ML service is down, submissions still work. If Redis is absent, requests still resolve. If a notification provider has no key, the others still fire. In an emergency system, partial function must never become total failure.

Anticipated Questions

Q&A Preparation

"Is this real ML or just rules?"

Both — and we label which is which. The photo classifier is genuine ML via HuggingFace. Prophet forecasting is a validated statistical model. Severity and misinformation classifiers are explicitly rule-based, marked 🧪 in our feature inventory.

"How is this different from NDEM?"

NDEM is credential-gated for officials and one-directional. We are public-facing, real-time, and bi-directional — citizens both receive alerts and contribute ground-truth reports. Complementary, not competing.

"How do you prevent duplicate events?"

A deterministic dedup_hash as a unique upsert key, plus source-level partitioning — the global USGS poller excludes the India bbox so Indian quakes are owned solely by the NCS proxy.

"What if a citizen submits a false report?"

Reports never auto-publish. Every submission enters a pending_review queue requiring explicit coordinator approval, with rate limiting at 5 per 10 minutes, an audit trail, and mandatory written justification for rejection.

"Can a coordinator see another state's data?"

No — blocked independently at four layers: API middleware scoping, route-level role checks, PostgreSQL Row-Level Security, and server-assigned Socket.io rooms. Compromising one layer does not grant access.

"What happens when a data source goes down?"

Each poller is independently scheduled and wrapped in error handling — one failing source cannot stall the others. The ingestion health panel surfaces the failure with its timestamp and error, and stale events auto-deactivate by TTL.
